Q&A & Logic Pipeline (closed-book LLM vs Prolog over the JSON KB)

    

      Tests how usable the extracted JSON KB is. Each provider proposes 2 questions about the paper
      (run sequentially so later models avoid duplicating earlier ones), giving 8 questions in total.
      For each question the pipeline produces:
      Path A — a closed-book LLM answer that sees only the JSON KB and not the paper, and
      Path B — a Prolog query rewritten from the question against the JSON-derived fact base.
      An LLM judge then classifies each pair as agree,
      disagree, or kb_silent.
      Run extraction first; the current JSON output and the abstract are used as inputs.
